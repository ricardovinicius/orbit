## After Implementation Review

- [ ] Check if the @docs/CODE_STYLE.md are being applied
- [ ] Check if the added documentation are really relevant, and have a natural tone
- [ ] Check if the tests follow the @docs/TESTING.md standards, and if they really test the feature
- [ ] Check if breaking changes like databases migrations, API contracts, external services integration, have a risk mitigation strategy like rollback, etc.
- [ ] Run quality tasks
- [ ] For UI changes, check with screenshots if they have a correct spacing and do not break the interface
